# How a genuine transcription enters the workflow

1. A specialist supplies a manifest, original file, contributor identity, source method, policy, machine-assistance disclosure, and limitations.
2. Intake preserves the file and SHA-256 checksum without changing canonical data.
3. The project assesses provenance and reviewer authority.
4. A primary specialist receives a scoped assignment and submits line/region readings.
5. A distinct second reader receives a blind package and submits an independent reading.
6. Comparisons preserve both readings and classify differences.
7. Authorized adjudication resolves or retains disagreements as uncertainty.
8. A candidate proposal is generated and validated against the canonical fingerprint.
9. Only an explicitly confirmed, provenance-complete proposal can be considered for guarded canonical application.

The current project stops before step 2 for scholarly material because no genuine submission is available.
