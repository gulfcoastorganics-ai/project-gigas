# Folio review workflow

1. Source captured. 2. Rights reviewed. 3. Asset checksum verified. 4. Transcription drafted. 5. Transcription compared. 6. Expansion reviewed. 7. Translation drafted. 8. Translation reviewed. 9. Regions aligned. 10. Citations checked. 11. Uncertainty reviewed. 12. Editorial approval. 13. Release gate checked.

Software validation supports integrity; it does not substitute for scholarly review.
