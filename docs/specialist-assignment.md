# Specialist assignment procedure

Assignments reference a preserved submission, its SHA-256 hash, a folio, a reviewer, a qualification record, role, date, status, and conflict-of-interest declaration. The authority matrix is checked before a reviewer is allowed to perform a scope. An assignment does not itself constitute review or verification.

The primary reviewer must submit before a second-reader assignment can advance into review. The primary and second reader must be different contributors, and both identities remain attributable in the audit trail.
