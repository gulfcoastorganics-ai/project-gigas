# Review failure and rejection states

Assignments and review workflows may be blocked or rejected for missing qualification, unauthorized scope, identity collision, undisclosed conflict, missing submission hash, malformed coordinates, stale package, invalid transition, incomplete disagreement, or unauthorized adjudicator.

Failure is preserved as an actionable workflow result. It is not converted into a pass by removing the record, hiding a disagreement, or changing a verification badge. The canonical repository remains unchanged when any review command fails.
