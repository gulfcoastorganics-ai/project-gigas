# Adjudication procedure

Adjudication is permitted only after primary and genuinely independent secondary readings have been submitted. The adjudicator must be authorized for the relevant scope. The record retains both readings, disagreement IDs, rationale, rejected alternatives, citations, and resulting verification state.

An unresolved disagreement blocks adjudication completion and canonical proposal readiness. Adjudication records are candidate-only and cannot write canonical data directly. A later canonical proposal must still pass fingerprint, provenance, validation, and explicit-apply safeguards.
